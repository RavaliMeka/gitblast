# Terraform Part 1: What is Terraform

Building blocks: sunny yellow with a stud-dot pattern, brick-shaped highlights, green baseplate captions, presenter on the right. The config file is an instruction booklet; bricks drop into place to build the same model every time; providers are plugins.

- `scenes.js`, `props.js`, `theme.py`: the episode; `python3 ../tools/build_episode.py .` builds `explainer.html`
- `preview.mp4`: silent preview with the planned timing
- Script and post caption: the "Terraform Series Scripts: Parts 1 to 4" doc
