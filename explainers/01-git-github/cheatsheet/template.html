Git Cheat Sheet

the commands you'll use every day

1Set up (once)

git config --global user.name "Your Name"

Tell Git who you are

git config --global user.email "you@mail.com"

Use your GitHub email

2Start a project

git init

Turn this folder into a Git repo

git clone <url>

Download an existing repo

3Save your work

git status

See what changed

git add .

Choose all changes to save (or git add <file>)

git commit -m "what you did"

Make a save point

4Sync with GitHub

git remote add origin <url>

Connect your repo to GitHub (once)

git push -u origin main

First upload; after that just git push

git pull

Get the latest changes

5Branches

git switch -c feature

Create a branch and move to it

git switch main

Go back to main

git merge feature

Bring the branch's work into main

git branch -d feature

Delete a merged branch

6Undo mistakes

git restore <file>

Throw away changes you haven't committed

git reset HEAD~1

Undo the last commit, keep the changes. Only if not pushed!

git revert <commit>

Safely undo a commit that's already pushed

7Look around

git log --oneline

History, one line per commit

git diff

Exactly what changed

git branch

List your branches

Daily flow:git pull→ edit →git add .→git commit→git push
